Two carbons with the same name, and how GRASP tells them apart

GRASP reads each atom as a short ID card. Some atoms that are chemically different get the exact same card. This walk-through shows a real feature inside GRASP that separates them anyway, and what an untrained copy of the same network does with the same molecule.

Input tokens layer 0

Numbers are real. Feature = latent 2610 of a 4,096-feature sparse autoencoder trained on GRASP layer 6 (50,000 ZINC molecules). Untrained copy = same architecture with random weights; its feature = latent 1875, the best match for "carbon carrying OH" out of its own autoencoder. Dataset scores: the 4,000-molecule atom set, all 16,090 atoms with token 150, 124 molecules that contain both an OH-carbon and a twin. Bar lengths are relative to each feature's largest value in these four molecules, since the two autoencoders use different units.
