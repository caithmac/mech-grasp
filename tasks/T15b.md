# T15b - Does GRASP-A2 USE its stereochemistry inputs? Enantiomers, diastereomers, and how far stereo travels

A2 receives atom stereo labels (R/S, r/s, unspecified, none) as input embeddings. A1 has no stereo input (control:
it must give IDENTICAL vectors for stereoisomers). Chemistry facts used below:
- Enantiomers (all centres inverted) are mirror images: identical in every achiral property (logP, solubility, TPSA).
- Diastereomers (only some centres inverted) are different compounds with genuinely different properties.

Setup: smi_all = data.get_smiles("mols") (50k). Using RDKit: for each SMILES m = Chem.MolFromSmiles(s);
centres = Chem.FindMolChiralCenters(m, includeUnassigned=False, useLegacyImplementation=False)
(returns specified tetrahedral centres only). Keep molecules with >= 1 centre; take the first 3000 (in order).
For each kept molecule build:
  enant: copy (Chem.Mol(m)), call atom.InvertChirality() on EVERY atom whose chiral tag is CHI_TETRAHEDRAL_CW/CCW,
         s_enant = Chem.MolToSmiles(copy)
  diast (only if >= 2 centres): copy, invert ONLY the atom of the first centre, s_diast = Chem.MolToSmiles(copy)
  rand: the SAME molecule written with a different atom order (A2 is order-invariant, so this should give ~0):
        perm = np.random.default_rng(i).permutation(m.GetNumAtoms()).tolist()
        s_rand = Chem.MolToSmiles(Chem.RenumberAtoms(m, perm), canonical=False)
  Skip a molecule if s_enant == s (meso / symmetric) - record how many were skipped.
For kind in ["a2", "a1"]: enc = model.load(kind); run model.run(enc, LIST, layers=[0, 2, 4, 6, 8, 12],
keep_atoms=False, dtype=np.float32) ONCE per list (original, enant, diast, rand), never per molecule.
Part 1 - representation distance (per layer, CLS and mean-pool): rel(a, b) = ||a - b|| / ||a||, mean over molecules,
  for (orig, enant), (orig, diast), (orig, rand). Scale reference: (orig, a different random molecule from the kept
  set, rng 0) at the same layer.
  ratio_diast_enant[L] = mean rel(orig,diast) / mean rel(orig,enant) on the molecules that have BOTH.
Part 2 - does stereo change property read-outs? Using the cached 50k molecule set for training:
  Am = data.get_acts("mols", kind); dm = data.get_mol_labels("mols"); scaf_m = np.asarray(data.get_scaffolds("mols"))
  for L in [6, 12]: P = probes.FixedProbe(Am.mean[L], dm["logp"].values, scaf_m); report P.score(Am.mean[L]) and
  mean |P.decision(enant.mean[L]) - P.decision(orig.mean[L])| and the same for diast and rand.
  (Note the cached Am rows are the canonical SMILES; your orig list is the same canonical SMILES, so orig vectors
  equal the cached ones up to float16 rounding.)
Part 3 - how far does stereo information spread through the graph (A2 only)? For the kept molecules with exactly
  one specified centre, run original and enant with keep_atoms=True, layers [0, 2, 4, 6, 8, 12]
  (one call each). For every atom compute rel = ||enant_i - orig_i|| / ||orig_i|| and bin by graph distance from the
  stereocentre (labels.distance_matrices on the ORIGINAL SMILES; atom order of the enant SMILES differs, so map
  atoms with orig_mol.GetSubstructMatch(enant_mol, useChirality=False) -> match[k] is the enant atom index for
  original atom k). Bins "0","1","2","3","4+". Mean per bin per layer.
results.json: {"n_kept", "n_meso_skipped", "n_with_diast",
  kind: {"rel": {pair: {"cls": {L}, "mean": {L}}}, "ratio_diast_enant": {"cls": {L}, "mean": {L}},
         "logp_probe": {L: {"score", "d_enant", "d_diast", "d_rand"}}},
  "spread_a2": {L: {bin: mean}}}
