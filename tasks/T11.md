# T11 - Lipinski rule of 5 on data that actually violates it (Tox21 + ClinTox)

Concatenate the two sets in the order tox21 then clintox: smiles, data.get_mol_labels rows, data.get_scaffolds,
and for kinds "pretrained" and "random": acts.mean[6] and acts.cls[12]. Then drop duplicate SMILES (keep first),
applying the same row index to every array.
Report n and violation rates of ro5_mw, ro5_logp, ro5_hbd, ro5_hba and (ro5_pass == 0).
Readouts, built separately and stored under different keys: X["mean6"] = mean[6], X["cls12"] = cls[12].
assert not np.allclose(X["mean6"], X["cls12"]) before any fitting.
For each readout and kind:
  1. Targets ro5_mw, ro5_logp, ro5_hbd, ro5_hba, ro5_pass (as int). Skip a target with < 30 positives or < 30
     negatives (record it under "skipped"). P_t = probes.FixedProbe(X, y, groups=np.asarray(scaffolds)); AUROC = P_t.score(X).
  2. Threshold vs continuous: P_c = probes.FixedProbe(X, logp, groups) (regression; same scaffold split because same
     groups and seed). AUROC of P_c.decision(X)[P_logp.test_idx] against ro5_logp[P_logp.test_idx].
     Same for mw vs ro5_mw.
  3. Direction test (pretrained only): cosine of P_pass.w with each flag's P_t.w, and R2 of the least-squares
     reconstruction of P_pass.w from the stacked flag directions (np.linalg.lstsq).
results.json: {"n", "violation_rates", "mean6": {kind: {...}}, "cls12": {kind: {...}}, "skipped": [...]}
