# T15a - GRASP-A2 gets bond types (incl. AROMATIC bonds) and stereo as INPUTS. Does it still compute chemistry?

GRASP-A2 = GRASP-A1 + explicit bond inputs (single/double/triple/aromatic, as per-head attention biases) + atom/bond
stereo embeddings. So bond aromaticity is now handed to the model; ring size, hybridization, conjugation, Crippen
contributions and functional-group context are still NOT inputs (they must be computed from the graph).
The right control for A2 is "a2_random" (A2 architecture, random weights, SAME bond/stereo inputs): anything it
also decodes comes from the inputs, not from learning. Compare with A1 vs "a1_random" (no bond inputs).

Setup: smi = data.get_smiles("atoms"); scaf = data.get_scaffolds("atoms"); df = data.get_atom_labels("atoms").
Pairs (first = model, second = its random control; probe result keys are always "grasp" and "random"):
  ("a2", "a2_random") and ("a1", "a1_random"); acts = data.get_acts("atoms", kind). Layers [0, 2, 4, 6, 8, 10, 12].
Concepts (use probes.probe_atoms(y, M, Rnd, scaf, layers=LAYERS, ...)):
  aromatic        : df.aromatic, ambiguous_only=True
  ring_size       : df.min_ring_size as int, mask = df.min_ring_size > 0 (multi-class -> balanced accuracy)
  hybridization   : df.hybridization, ambiguous_only=True
  conjugated      : df.conjugated, ambiguous_only=True
  crippen         : df.crippen_logp_contrib (regression R2)
  mr              : df.crippen_mr_contrib (regression R2)
  o_neighbor_C    : df.has_O_neighbor, mask = (df.tok_element == "C")
  halogen_nbr_C   : df.has_halogen_neighbor, mask = (df.tok_element == "C")
Wrap each probe_atoms call in utils.memo(f"t15a_{pair}_{concept}_v1", ...).
For every concept, pair and layer report model mean/std, control mean/std, token baseline, and the ERROR (1 - score).
Derived per concept and pair: best layer, best model error, control error at that layer,
learned_gain = control_error / model_error at the best layer (how many times better than the input-only control).
results.json: {concept: {"a2": {"layers": {L: {"model", "model_std", "control", "control_std"}}, "token", "best_layer",
                                "best_err", "control_err_at_best", "learned_gain"},
                         "a1": {...same}}}
Figure t15a.png: one panel per concept, error vs layer (log y): a2 solid, a2_random dashed, a1 solid, a1_random dashed.
