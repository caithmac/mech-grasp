# T04 - Lipinski rule of 5: thresholds or just continuous properties?

Data as in T03 (mols set). Targets: ro5_pass, ro5_violations, ro5_mw, ro5_logp, ro5_hbd, ro5_hba
(binary/ordinal, from data.get_mol_labels("mols")).

1. probes.probe_mols for each (pool="cls", layers=[0,4,8,12]). Note class imbalance: report the
   positive rate of each binary target.
2. Threshold test: for ro5_logp, compare (i) a logistic probe on GRASP CLS (best layer) predicting
   ro5_logp directly vs (ii) the GRASP CLS ridge-probe prediction of continuous logp thresholded at 5.
   If (i) is not better than (ii), the model represents logP, not "the Lipinski rule". Do this with a
   scaffold split (sklearn GroupShuffleSplit, test_size=0.2, random_state=0), StandardScaler, Ridge(alpha=10),
   LogisticRegression(C=0.1, max_iter=1000, class_weight="balanced"). Report AUROC for both, and
   balanced accuracy for both.
3. Direction test: fit logistic probes for ro5_mw, ro5_logp, ro5_hbd, ro5_hba and ro5_pass on best
   layer CLS (standardised). Report cosine similarity between the ro5_pass weight vector and each of the
   other four, and R2 of reconstructing the ro5_pass weight vector as a linear combination of the four
   (least squares).

results.json: "probes", "positive_rates", "threshold_test", "direction_test".
