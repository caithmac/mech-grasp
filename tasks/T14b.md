# T14b - Why does layer 12 blur chemistry? Test 2: is the information LOST or only re-encoded non-linearly?

A linear probe failing at layer 12 can mean (a) the information is gone, or (b) it is still there but not
linearly readable. probes.MLPProbe (one hidden layer, same scaffold split as FixedProbe for the same seed and
mask) separates the two: if the MLP recovers the layer-6 score at layer 12, the information was re-encoded;
if the MLP also drops, it was discarded.

Setup: df = data.get_atom_labels("atoms"); scaf = np.asarray(data.get_scaffolds("atoms")).
Concepts (y, mask):
  crippen      : df.crippen_logp_contrib (regression, R2), all atoms
  mr           : df.crippen_mr_contrib (regression, R2), all atoms
  aromatic     : df.aromatic as int, mask = carbon ring atoms (tok_element == "C" & tok_in_ring == 1)
  ring5        : (df.min_ring_size == 5) as int, mask = ring atoms with min_ring_size in {5, 6}
  o_neighbor   : df.has_O_neighbor as int, mask = carbons (tok_element == "C")
Kinds: ["pretrained", "a1_step1", "random"]. Layers: [4, 6, 8, 10, 12]. Seeds: [0, 1].
For each kind, layer, concept, seed (A = data.get_acts("atoms", kind), groups = scaf[A.mol_index]):
  lin = probes.FixedProbe(A.atom[L], y, groups, seed=s, mask=mask).score(A.atom[L])
  mlp = probes.MLPProbe(A.atom[L], y, groups, seed=s, mask=mask).score(A.atom[L])
Report mean over seeds of lin and mlp, and for regression the ERROR 1 - R2, for AUROC the error 1 - AUROC.
Derived per kind and concept: lin_drop = lin_err[12] / lin_err[best layer]; mlp_drop = mlp_err[12] / mlp_err[best layer]
(best layer = layer with the lowest error for that probe type). retained = (mlp at 12) vs (lin at best layer).
Wrap each (kind, concept) block in utils.memo(f"t14b_{kind}_{concept}_v1", ...) - MLP fits take ~10-60 s each.
results.json: {kind: {concept: {"lin": {L: mean}, "mlp": {L: mean}, "lin_err": {L}, "mlp_err": {L},
                                "lin_drop": float, "mlp_drop": float, "best_layer_lin": int, "best_layer_mlp": int}}}
Figure t14b.png: one panel per concept, error (log scale) vs layer, solid = linear, dashed = MLP, colour = kind.
Questions: at layer 12, is the chemistry lost (MLP error also rises a lot) or re-encoded (MLP error stays near its
best)? Is the pattern the same in a1_step1 (RTD only, never saw assays)? Does random-init show any of this?
