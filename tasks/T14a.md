# T14a - Why does layer 12 blur chemistry? Test 1: is the last layer specialised for replaced-token detection?

Background (from the GRASP README): Step 1 pretraining is ELECTRA-style graph replaced-token detection (RTD):
25% of atom positions get a generator-proposed token, and the 12-layer discriminator must say, for EVERY atom,
whether its token was replaced. The RTD head reads layer 12. Earlier checkpoints showed that chemistry
(Crippen contributions, ring size, aromaticity) is most decodable around layers 4-8 and DEGRADES at layer 12, in
GRASP, GRASP-A1 and A1 Step-1 alike. Hypothesis: layer 12 is re-shaped into an "is this token consistent with
its context?" signal for the RTD head, discarding chemistry it does not need for that decision.
The head weights are not released, so we rebuild the task: corrupt tokens ourselves and probe for "replaced".

Setup: smi = data.get_smiles("atoms"); A = data.get_acts("atoms", "pretrained"); df = data.get_atom_labels("atoms");
scaf = np.asarray(data.get_scaffolds("atoms")).
Replacement proposals (a crude generator): from A.tokens and df.tok_element build, per element, the frequency
of each token. rng = np.random.default_rng(0). For each molecule m, choose k = max(1, round(0.15 * n_atoms))
atoms uniformly without replacement; for each chosen atom draw a new token from the SAME element's token
distribution with the original token removed (renormalise); skip the atom if its element has only one token.
Record per atom: replaced (0/1), same_degree (replacement token has the same tok_degree as the original, look up
the degree of a token id from df rows carrying it), and keep override = {m: {a: new_tok}}.
LAYERS = [0, 2, 4, 6, 8, 10, 11, 12].
For kind in ["pretrained", "a1_step1", "a1", "random"]:
  enc = model.load(kind); C = model.run(enc, smi, layers=LAYERS, token_override=override)   (float16 default)
  groups = scaf[C.mol_index]
  For each L: rtd_auroc[L] = probes.FixedProbe(C.atom[L], replaced, groups).score(C.atom[L])
              rtd_auroc_samedeg[L] = same but mask = (replaced == 0) | (same_degree == 1)
              (the hard case: the replaced token's degree matches the graph, so only chemistry can reveal it)
  Also, on the CLEAN cached activations (data.get_acts("atoms", kind); layers as available, plus run
  model.run(enc, smi, layers=[11]) to get layer 11 for kinds that do not cache it), per L:
     geometry: on a fixed random subsample of 20000 atom rows (np.random.default_rng(1)):
       pr = utils.participation_ratio(X); aniso = mean cosine similarity of rows to their mean vector;
       top1, top10 = fraction of variance in the first 1 and 10 principal components (centred X);
       outlier = max_d |mean_d| / median_d |mean_d| over the 768 dimensions (massive-activation check).
  RTD-direction alignment at L = 12 and L = 6: w = FixedProbe(C.atom[L], replaced, groups).w / ||w||;
     var_frac_rtd[L] = variance of clean X @ w divided by the mean per-direction variance (total var / 768)
     (>> 1 means clean activations vary a lot along the RTD axis); cos_pc[L] = |cos(w, PC_i)| for PCs 1..5.
  Delete C before the next kind (memory).
results.json: {kind: {"rtd_auroc": {L}, "rtd_auroc_samedeg": {L}, "geometry": {L: {"pr", "aniso", "top1", "top10", "outlier"}},
               "var_frac_rtd": {"6", "12"}, "cos_pc": {"6": [5], "12": [5]}}, "n_replaced": int, "n_samedeg": int}

Questions: does "replaced?" become MOST decodable exactly at the last layers (11-12) of the trained models while
chemistry decodability falls there? Does the random model stay low? Does the representation collapse
(lower participation ratio, higher anisotropy) at layer 12, and do clean activations vary strongly along
the RTD direction at layer 12 but not layer 6?
