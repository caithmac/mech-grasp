# T01b - HARD atom-level probes: atoms the input token cannot classify

T01 showed AUROC saturates near 0.99 on all atoms (most atoms are easy from the token alone). This task
uses probes.probe_atoms(..., ambiguous_only=True), which keeps only atoms whose input token occurs with
more than one label value. Report ERROR = 1 - score for every number.

Columns: aromatic, conjugated, has_O_neighbor, has_N_neighbor, has_halogen_neighbor, fg_carbonyl_C,
fg_amide, fg_ester, fg_carboxylic_acid, fg_nitrile, fg_aromatic_N, fg_michael_acceptor, fg_ether,
fg_hydroxyl, min_ring_size, n_rings.
Layers: list(range(13)). Seeds: default (3).
Use data.get_acts("atoms","pretrained"), data.get_acts("atoms","random"), data.get_atom_labels("atoms"),
data.get_scaffolds("atoms").

results.json:
  "<column>": the probe result dict,
  "summary": list of rows {column, n_atoms, token_error, best_layer (lowest GRASP error),
     grasp_error_best, random_error_at_best, grasp_error_layer12, error_ratio_random_over_grasp,
     first_layer_beating_random_by_3std}
Figure errors.png: one subplot per column, x = layer, y = error (log scale), lines grasp / random /
token (flat), with std bands.
