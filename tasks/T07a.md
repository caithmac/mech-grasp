smi = data.get_smiles("atoms")[:1000]; D = labels.distance_matrices(smi).
Attention:
  pretrained: Aa = data.get_acts("atoms", "pretrained", attention=True); use Aa.attn[l][m] for m < 1000.
  random, a1: att = model.run(model.load(kind), smi, attention=True, layers=[12]).attn  (attention is returned for
  all 12 layers regardless of `layers`).
Aa.attn[l][m] has shape (12 heads, n+1, n+1): index 0 = CLS, atom i = index i+1; rows = queries, columns = keys.

For every model, layer l (0..11), head h, using ATOM query rows only (rows 1..n), per molecule then averaged:
  - mass_cls  = mean attention on key 0 (CLS)
  - mass_d[k] = mean total attention on atom keys at graph distance k from the query; k in "0","1","2","3","4+"
  - entropy   = mean Shannon entropy (nats) of the attention row
  - chance_d[k] = mean fraction of the n+1 keys falling in distance bin k (same for every head)
Label each head (first rule that matches): "self" if mass_d[0] > 0.5; "neighbour" if mass_d[1] > 0.5;
"cls_sink" if mass_cls > 0.5; "local" if mass_d[0]+mass_d[1]+mass_d[2] > 0.7; else "diffuse".
Vectorise per molecule with numpy (a molecule's attention is a (12, n+1, n+1) array; build distance-bin masks once).

results.json: {model: {"mass_cls": 12x12, "mass_d": {k: 12x12}, "chance_d": {k: float}, "entropy": 12x12,
               "labels": 12x12 strings, "label_counts_per_layer": [ {label: count} for each layer ]}}
for model in ["pretrained", "random", "a1"].
