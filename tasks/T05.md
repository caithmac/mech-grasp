# T05 - Chemical consistency of the embedding

Use model.load("pretrained") and model.load("random") and model.run on NEW molecules you build.
Distances = cosine distance of layer-12 CLS (cast to float32). Also report layer-6 CLS.
For every test report pretrained AND random-init numbers.

1. "constitutional_isomers": take 300 molecules from data.get_smiles("atoms"). For each, build an
   isomer with the SAME bag of input tokens but different connectivity is hard - instead compare:
   (a) pairs of molecules from the set with identical molecular formula (rdMolDescriptors.CalcMolFormula)
       but different canonical SMILES (find all such pairs in the 4k set, cap 500), vs
   (b) random pairs with |heavy_atoms difference| <= 1 (500 pairs).
   Report mean/median distance for (a) and (b). Does same-formula imply similar embedding? (It should
   NOT if the model encodes structure rather than composition.) Also report the Tanimoto similarity
   (Morgan r2, 2048 bits) of each pair and the Spearman correlation between embedding distance and
   (1 - Tanimoto) across all (a)+(b) pairs.
2. "group_swaps": matched molecular pairs. For 300 molecules containing an aromatic C-H that can take a
   substituent, make variants by replacing ONE aromatic H with: F, Cl, OH, NH2, CH3, C(=O)O, C#N,
   [N+](=O)[O-]. Easiest: use SMARTS reaction rdkit AllChem.ReactionFromSmarts("[cH:1]>>[c:1]X") with
   X the substituent, take the first sanitizable product. Compute difference vectors
   delta = CLS(variant) - CLS(parent) per substituent. Report for each substituent: mean pairwise cosine
   similarity of the delta vectors across molecules (consistency; high = model has a stable "add -X"
   direction), and the cosine similarity matrix between mean delta vectors of different substituents.
   Chemist will check whether e.g. F/Cl cluster, and OH/NH2 cluster.
3. "rewiring": for 300 molecules, make a degree-preserving rewired graph: pick two non-ring single
   bonds A-B and C-D between heavy atoms (4 distinct atoms), replace with A-D and C-B using
   Chem.RWMol, sanitize; keep only results that sanitize, remain one fragment, and have the SAME sorted
   input-token list (compute tokens via model.run(...).tokens). Then train a logistic probe
   (scaffold-agnostic 5-fold sklearn cross_val_score, roc_auc) to classify original vs rewired from
   layer-12 CLS, for pretrained, random, and bag-of-tokens counts (should be ~0.5 by construction).
   Also report the mean CLS distance original->rewired.

results.json keys: "constitutional_isomers", "group_swaps", "rewiring" (include n of valid examples).
Figure: heatmap of substituent mean-delta cosine matrix (swaps.png).
