# T02 - Does GRASP carry atom-level logP the way Crippen does?

Crippen logP is a sum of per-atom contributions determined by each atom's local chemical type.
If GRASP learned chemistry, per-atom activations should linearly encode the Crippen atom
contribution (crippen_logp_contrib) and molar refractivity contribution (crippen_mr_contrib),
beyond what the input token gives.

1. probes.probe_atoms for crippen_logp_contrib and crippen_mr_contrib, layers 0..12 (pretrained vs random,
   token baseline).
2. Same, restricted to carbon atoms only (mask = df.tok_element=="C"), because carbon Crippen types depend
   on neighbours (aromatic, attached to heteroatom, etc.).
3. Molecule-level additivity check: fit a Ridge (sklearn, alpha=10) per-atom on the BEST layer's atom
   activations to predict crippen_logp_contrib using molecules whose scaffold is in a train split
   (sklearn GroupShuffleSplit test_size=0.2, random_state=0, groups = scaffold per atom). On the
   test molecules, sum predicted per-atom contributions per molecule and compare to RDKit
   Crippen.MolLogP(mol) for those molecules: report R2 and MAE. Do the same with the random-init model
   and with a one-hot token model (same pipeline). Cast activations to float32.
