Question: does the analysis pipeline behave as expected on GRASP?

Do all of the following and put each result under its own key in results.json:
1. "smiles_invariance": for 200 molecules from data.get_smiles("atoms"), make 3 random non-canonical
   SMILES each (rdkit Chem.MolToSmiles(mol, doRandom=True)). Encode with model.run on the pretrained
   model. Report max and mean cosine distance of layer-12 CLS between each variant and the canonical
   form. Expected: ~0 (graph model should be invariant to atom order up to float16 noise).
2. "stereo_blindness": 10 pairs of stereoisomers (e.g. "C/C=C/C" vs "C/C=C\C", "C[C@H](N)O" vs
   "C[C@@H](N)O", plus 8 drug-like ones you build with chiral centres). Report cosine distance of
   layer-12 CLS per pair. Expected: ~0 (model has no stereo input).
3. "pretrained_vs_random": on the cached "atoms" set, mean cosine similarity between pretrained and
   random-init CLS at layer 12 (should be unrelated), and the per-layer average norm of A.atom[l]
   for both models (list of 13 values each).
4. "token_check": using data.get_atom_labels("atoms"), for each token id count how many distinct
   values of the 'aromatic' column occur. Report the number of tokens that mix aromatic and
   non-aromatic atoms and the fraction of atoms carried by such tokens.
   (This measures how much aromaticity information the input token is MISSING.)
5. "cls_effective_rank": participation ratio (sum(eig)^2/sum(eig^2)) of the covariance of layer-12
   CLS over the "mols" set, for pretrained and random.
