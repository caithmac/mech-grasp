# T15c - SAE on GRASP-A2 layer 6: does A2 still build context-chemistry features, or are they now inputs?

Same recipe as T08b (pretrained GRASP had 93 "context_chemistry" latents, random-init had 0), applied to A2.
A2 is given bond types (including aromatic bonds) and stereo; so concepts derived from bond type alone
(aromatic, conjugated, hybridization) may now be cheap; functional-group context (fg_*, has_*_neighbor,
ring size) still has to be computed.

Setup: A = data.get_acts("atoms", "a2"); R = data.get_acts("atoms", "a2_random"); df = data.get_atom_labels("atoms").
SAEs (cached by name after the first call; ~10 min each):
  X, _, _ = data.get_sae_acts(6, "a2"); S = sae.load_or_train("mols_a2_L6", X, n_latents=4096, k=32); del X
  Sr = sae.load_or_train("atoms_a2_random_L6", R.atom[6], n_latents=4096, k=32)
Report S.stats(A.atom[6]) and Sr.stats(R.atom[6]) (fvu, n_alive, dead_frac; drop fire_counts from the json).
Concepts (boolean per atom, matrix C): aromatic; min_ring_size == 3,4,5,6,7; hybridization == "SP","SP2","SP3";
conjugated; has_O_neighbor; has_N_neighbor; has_halogen_neighbor; every column starting with "fg_".
Drop concepts with < 10 positives.
Z = S.encode(A.atom[6]) -> scipy.sparse.csc_matrix immediately (keep only the sparse copy). Same for Sr on R.atom[6].
For each latent j firing on >= 20 atoms (z = Z[:, j].toarray().ravel()):
  tok_j = most common token among firing atoms; purity_j = fraction of firing atoms with tok_j.
  within-token: rows with token == tok_j; for each concept with >= 10 positives AND >= 10 negatives in those rows,
  AUROC of z vs concept -> best_within concept + AUROC (None if no concept qualifies).
  class: "context_chemistry" if best within-token AUROC >= 0.9; elif purity_j >= 0.9: "token"; else "mixed".
Group context_chemistry latents by their best concept into families:
  "bond_derived" = aromatic, conjugated, hybridization_*; "ring" = min_ring_size_*; "neighbour" = has_*_neighbor;
  "functional_group" = fg_*.
For a fair comparison with random-init, also repeat the latent analysis for S on a random subsample of 96,000 atoms
is NOT needed (atoms set is already ~93k atoms); just report both on the atoms set.
results.json: {"a2": {"stats", "counts": {"context_chemistry", "token", "mixed"}, "families": {family: count},
                      "top_context": [25 x {"latent", "tok", "element", "concept", "within_auroc", "n_fire"}]},
               "a2_random": {"stats", "counts", "families"}}
Reference numbers from pretrained GRASP (T08b, same atoms set): 93 context_chemistry latents at >= 0.9; FVU 0.075.
Questions: how many context-chemistry latents does A2 have vs GRASP's 93, and how many does a2_random have
(with bond inputs the random control might now show some)? Which families shrink or grow relative to GRASP?
